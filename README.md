# Gretel's Plug 2020 - Air_Luxe Bespoke Fashion Atelier

> *"DRIVEN BY QUALIFYING AND CHOSEN BY THOSE WHO KNOW THE DIFFERENCE."* (Est. 2020)

A high-end, modern digital atelier platform for **Air_Luxe** (*Gretel's Plug 2020*), specializing in bespoke custom-made luxury outfits, haute couture evening gowns, tailored suits, and silk luxury attire.

---

## 🌟 Key Features

- **Direct WhatsApp Order System**: Every outfit allows clients to choose fabric swatches, input standard or custom body measurements (Bust/Chest, Waist, Hips, Height, Outfit Length), and trigger pre-formatted WhatsApp consultation messages.
- **Passcode Security Lock**: Protected **Admin Atelier Manager** modal (Default PIN: `2020` or press `Ctrl + Shift + A`) to manage product items, prices, and upload gallery photos directly from your phone or computer.
- **Gallery & Device Photo Upload**: Add photos directly from your device gallery without requiring external image hosting.
- **Dynamic Editorial Lookbook**: Highlights active signature outfits with instant quick-view and WhatsApp order triggers.
- **Size & Measurement Guide**: Step-by-step home measurement instructions for custom fitting.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite 5 + TypeScript
- **Styling**: Tailwind CSS 3 (Warm Cream, Luxe Gold, and Charcoal Slate palette)
- **Icons**: Lucide React
- **Deployment**: Vercel ready with `vercel.json` SPA configuration

---

## 🚀 Local Setup & Development

```bash
# Clone repository
git clone https://github.com/Noratom/Gretel-sPlug.git

# Navigate into directory
cd Gretel-sPlug

# Install dependencies
npm install

# Run dev server
npm run dev
```

Open `http://localhost:5173` in your browser.

---

## 🌐 Deploy to Vercel

```bash
npx vercel
```
Or import this repository directly on [Vercel Dashboard](https://vercel.com).
